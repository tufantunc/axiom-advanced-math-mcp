## Design

Clusters of adjacent `it(...)` tests sharing one assertion shape become a
single `it.each` table (vitest, already the house pattern in the ode tests).

Invariants:
- Assertions stay byte-identical per cluster — a `toContain` cluster keeps
  `toContain`, a `toBe('Result: …')` cluster keeps `toBe`; previously
  hardened pins are never relaxed.
- Per-test comments survive as table comments or sit above the `it.each`.
- Heterogeneous tests (extra assertions, e.g. router's csolve domain check,
  verify's diagnostic-pin FALSE test, http-app's 403 rejects) stay separate
  `it`s; the uniform remainder parametrizes and the group drops below 3.
- Vitest counts each table row as a test — the reported test count must not
  change.

Files: combinatorics (catalan/derangements/partition), advanced-solve (6
clusters), router (5), verify (TRUE cluster), integration (arithmetic +
trigonometry), geometry3d-router, http-app (Host allowlist).

One commit; five gates with the row-count invariant; then review-pro
(correctness first, mutation tests reviewer alone last).
