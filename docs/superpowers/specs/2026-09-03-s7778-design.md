# S7778 — combine consecutive push() calls

Date: 2026-09-03

## Design

One transformation: consecutive statements pushing to the SAME receiver
become a single push with the arguments in the original order. Argument
evaluation is left-to-right in both forms, so behaviour and output order are
identical.

- probability-calc.ts ×32 (clusters of 2-4), numerical-methods.ts ×8,
  plot/svg-renderer.ts ×6, sequence-utils.ts ×5, fourier-transform.ts ×2,
  advanced-solve-service.ts, linear-regression.ts, number-utils.ts ×1 each.
- No oxlint equivalent rule exists, so no autofix and no permanent guard —
  recorded here as a known gap; the strong output-line pins in the suite are
  the safety net.
- Method: a strict Python transformer merges ONLY adjacent single-line
  `X.push(...);` statements whose argument part is paren-balanced (arguments
  can contain `);` inside templates, hence the balance check); multi-line
  push statements are converted by hand. Per-file assertion counts and a diff
  review accompany every file.
