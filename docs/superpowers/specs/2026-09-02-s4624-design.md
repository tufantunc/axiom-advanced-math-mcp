# S4624 — flatten nested template literals

Date: 2026-09-02
Branch: `fix/sonar-s4624` (from `main` 712b2ce)
Rule: typescript:S4624 — template literals should not be nested (17 findings;
one — fourier-transform.ts:63 — was already resolved by the S3358 round).

## Design

Two shapes, one fix: hoist the inner template to a named const on the line
above, so no template sits inside another's `${}`.

- **map-join builders** (geometry.ts:94, linear-regression.ts:22-23,
  multivariable/operators.ts:30, multivariable/optimization.ts:8 and :105,
  verify/index.ts:204, ode-system.ts:239-240 and :496-500): the inner
  `.map(x => `…${x}…`).join(…)` becomes a const; the outer template
  interpolates the const. For ode-system's three-part `probe` and two-part
  `degrees` (strings handed to Giac) each part becomes its own const — the
  concatenation order is untouched, and a probe script byte-compares old and
  new constructions for representative inputs.
- **conditional templates** (number-utils.ts:61,64,66,
  self-verify.ts:185): `cond ? `Yes (…)`` : 'No'` inside an outer template
  becomes a const line above.

All conversions are pure renames; outputs are byte-identical. One commit,
five gates, then review-pro with the correctness reviewer first and the
mutation tests reviewer last and alone.
