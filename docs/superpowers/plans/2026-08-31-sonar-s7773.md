### Task 2: Compound collapses, rider fixes, full verification, single commit

**Files:**

**Interfaces:**
- Consumes: Task 1's autofixed tree (all sites already `Number.`-prefixed).
- Produces: a clean tree — `npm run lint` at 0 warnings — ready to commit.

- [ ] **Step 1: Collapse the compound check in `response-formatter.ts`**

The autofix will have produced `!Number.isNaN(rounded) && Number.isFinite(rounded)`. Replace:

```ts
    if (!Number.isNaN(rounded) && Number.isFinite(rounded)) {
```

with:

```ts
    if (Number.isFinite(rounded)) {
```

(`Number.isFinite` is false for both `NaN` and `±Infinity`, so the conjunct is redundant — rounded is a `parseFloat` result, i.e. statically `number`.)

- [ ] **Step 2: Collapse the compound check in `verify/index.ts`**

Replace:

```ts
        if (Number.isNaN(numResult) || !Number.isFinite(numResult)) {
```

with:

```ts
        if (!Number.isFinite(numResult)) {
```

Keep the existing trailing comment (`// Skip undefined points`) on its own line exactly as-is.

- [ ] **Step 3: Rider — replace `new Array(...)` at `combinatorics.ts:44`**

Replace:

```ts
  const table: bigint[][] = Array.from({ length: n + 1 }, () => new Array(k + 1).fill(0n));
```

with:

```ts
  const table: bigint[][] = Array.from({ length: n + 1 }, () => Array.from({ length: k + 1 }, () => 0n));
```

- [ ] **Step 4: Rider — replace `new Array(...)` at `combinatorics.ts:175`**

Replace:

```ts
        const p = new Array(n + 1).fill(0n);
```

with:

```ts
        const p = Array.from({ length: n + 1 }, () => 0n);
```

(Both riders produce the identical dense `0n`-filled array; `new Array(len).fill(v)` and `Array.from({ length: len }, () => v)` are behaviorally equal, and `test/combinatorics.test.ts` covers Stirling numbers and partition counts.)
